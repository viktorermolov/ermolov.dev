Google removed the remaining Manifest V2 extensions from the Chrome Web Store on August 31, 2026. This was a separate step from disabling Manifest V2 extensions in Chrome during 2025. See [Google's official timeline](https://developer.chrome.com/docs/extensions/develop/migrate/mv2-deprecation-timeline) for the distinction.

If your old clipboard extension is unavailable, start with the task you need to replace. For saving text copied on web pages and finding it later, Clipstay provides a local clipboard history in Chrome. You can search saved text, pin useful clips and copy a saved clip back to your clipboard in one click.

## Keep text you want to use again

Copy or cut text on a web page, then open Clipstay to find it in your history. This can be a reference from an article, a command from documentation or a short passage you want to use in a draft. Capture also works in tabs that were open before you installed the extension.

Search with several words in any order when you remember part of a clip. Use date or pinned-clip filters to narrow the list. Pin text you reuse so it is easier to find. When you select a saved clip to copy back, you can paste it where you need it.

## Choose what goes into your history

Your history is stored on your device. Clipstay has no account and no analytics. You can exclude sites or pause capture. Password fields and Incognito windows are not captured. If you copy passwords from a password manager, turn off “Add clipboard when the popup opens” in Settings, because that optional setting can add the current clipboard text.

Clipstay stores text only. Check its [capture details and controls](/clipstay/) before deciding whether it fits your routine. A replacement should match the actions you rely on, including how text is collected and how you paste it again.

## Try your everyday workflow

After installing, copy a few non-sensitive text snippets from web pages. Open Clipstay, search for one, pin a useful clip and copy it back. You can open the popup with Control+Shift+V on Mac or Alt+Shift+V on Windows and Linux. You can also export your Clipstay history to JSON or CSV.

Keep any export you already have from your previous tool. Do not assume that installing a new extension will recover its old history. Test the workflow you need before depending on it for important text.

Clipstay is an independent product.

## What is different

- Clipstay keeps a text history focused on copying and cutting on Chrome web pages.
- Reuse works by copying a saved clip back to the clipboard, then pasting it yourself.
- Opening the popup can optionally add the current clipboard text. Clipstay does not monitor other apps in the background.
- Your history is stored locally. This page makes no promise to restore or import another extension's saved data.
